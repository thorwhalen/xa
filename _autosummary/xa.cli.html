xa.cli¶

Command-line interface for xa.

Exposes subcommands via cw: list, info, history, spawn, resume, kill, serve, sync, pick, gen-secret, revive, and the archive group (list, log, forensics).

Entry point: xa (see [project.scripts] in pyproject.toml).

xa.cli.revive_cmd(apply=False, include_held_elsewhere=False, server_mode=False, min_interval=0.0, json_out=False)[source]¶

Report — and optionally reconnect — panes whose Remote Control dropped.

Prints one line per live claude pane with its verdict, so “nothing to do” is legible next to how much was looked at. Sends nothing without --apply.

Parameters:

  • apply (bool) – Actually send /remote-control. Off by default.

  • include_held_elsewhere (bool) – Also reconnect sessions taken over from another device. This steals them back — deliberate keystroke only.

  • server_mode (bool) – Also restart died claude remote-control servers.

  • min_interval (float) – Seconds before the same pane may be touched again (0 uses the default guard interval).

  • json_out (bool) – Emit JSON instead of the table.

Return type:

None

xa.cli.serve_cmd(host='127.0.0.1', port=8010, mount='', username=None, password=None, password_env=None, captcha=False, webui=True, default_folder=None, i_know_its_insecure=False)[source]¶

Run the xa HTTP service (requires the xa[service] extra).

Secure by default. Refuses to bind to a non-loopback interface without HTTP Basic credentials. Override this guardrail with --i-know-its-insecure only in locked-down deployments (e.g. behind an mTLS-terminating proxy).

Parameters:

  • host (str) – Bind host. 127.0.0.1 by default — only this machine.

  • port (int) – Bind port.

  • mount (str) – Optional mount prefix (e.g. /api/xa).

  • username (Optional[str]) – HTTP Basic username.

  • password (Optional[str]) – HTTP Basic password. Prefer --password-env.

  • password_env (Optional[str]) – Name of env var to read the password from (recommended).

  • captcha (bool) – Enable captcha-gated deletes. Strongly recommended for any non-loopback deployment.

  • webui (bool) – Serve the bundled web UI at the mount root (default on). Pass --no-webui to run API-only.

  • default_folder (Optional[str]) – Default working directory the webui prefills into the “new session” dialog and the folder chooser opens at. Falls back to $XA_DEFAULT_FOLDER or $HOME if unset.

  • i_know_its_insecure (bool) – Skip the public-bind-without-auth safety check.

Return type:

None
